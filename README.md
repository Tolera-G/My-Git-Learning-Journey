# My Git and GitHub Learning Journey

A practical, structured journey from Git and GitHub fundamentals to advanced professional workflows.

## About This Project

**My Git and GitHub Learning Journey** is a hands-on learning project documenting my journey of understanding and mastering Git and GitHub.

The goal is not simply to memorize commands, but to understand how Git works, why developers use it, and how it supports real-world software development and team collaboration.

Throughout this journey, I will combine theoretical understanding, practical exercises, personal experiments, and documentation to build a strong foundation in version control.

## Learning Objectives

By completing this journey, I aim to:

- Understand version control and Git fundamentals.
- Manage projects using local Git repositories.
- Work confidently with GitHub repositories.
- Understand remote repositories and synchronization.
- Create branches and collaborate with other developers.
- Work with GitHub organizations and project management tools.
- Contribute to open-source projects.
- Understand advanced Git workflows and professional practices.

## Learning Roadmap

This journey is organized into eight progressive phases, containing 80 lessons.

| Phase | Topics |
|---|---|
| 01 | Git Fundamentals |
| 02 | Working with Local Git |
| 03 | GitHub Foundations |
| 04 | Remote Repositories |
| 05 | Branching and Team Collaboration |
| 06 | Organizations and Project Management |
| 07 | Open-Source Contribution |
| 08 | Professional and Advanced Workflows |

Each phase builds upon the knowledge and practical experience gained in the previous phase.

## Learning Method

Every lesson follows a practical learning cycle:

1. **Understand:** Learn the concept and why it matters.
2. **See it:** Explore practical examples.
3. **Practise:** Perform hands-on exercises.
4. **Explain:** Test understanding through knowledge checks.
5. **Document:** Record important concepts and commands in Markdown.
6. **Review and Publish:** Review the work and publish it to GitHub.
