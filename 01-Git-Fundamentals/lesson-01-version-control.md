# Lesson 01: Version Control

## What is Version Control?
Version control is a system that records changes made to files over time. It helps us manage different versions of a project.

## What problem does it solve?
It allows us to return to an earlier version of a project without creating many separate copies. It also makes tracking and managing code changes easier.

## Why is it important?
Version control is important because it helps developers:
- Track what has changed.
- Know when changes were made.
- Identify who made the changes.
- Understand why changes were made through commit messages.
- Restore earlier versions when something goes wrong.

## What I learned
I learned what version control means, why we need it, and the problems it solves in software development.
