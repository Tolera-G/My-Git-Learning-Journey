# Phase 01: Git Fundamentals

## About This Phase

Welcome to the first phase of the Git and GitHub Learning Journey!

In this phase, we introduce the basic concepts of Git and learn how it helps developers manage changes in their projects.

The lessons are designed for beginners with little or no previous experience using Git.

## Learning Objectives

By the end of this phase, you should be able to:

- Understand the purpose of version control.
- Explain the difference between Git and GitHub.
- Install and configure Git.
- Understand what a Git repository is.
- Initialize a project as a Git repository.

## Learning Approach

Each lesson combines simple explanations, practical examples, and exercises to help learners understand and apply Git concepts.

Learners are encouraged to practise commands in their own terminal rather than simply memorize them.

## Expected Outcome

After completing this phase, learners will understand the basic purpose and setup of Git and will be ready to start working with local repositories.
