# Lesson 21: Navigating a GitHub Repository

## Learning objectives
- Understand the main sections of a GitHub repository.
- Navigate repository files and folders.
- Explore commit history.
- Understand the purpose of the About section.

## Core idea

A GitHub repository contains different sections that help developers manage source code, documentation, collaboration, automation, and project settings.

## Important repository sections

| Section | Purpose |
|---|---|
| Code | Displays project files and folders |
| Issues | Tracks bugs, tasks, and feature requests |
| Pull requests | Proposes and reviews changes |
| Actions | Automates workflows |
| Projects | Organizes project work |
| Wiki | Stores additional documentation |
| Security | Provides security-related information |
| Insights | Displays repository activity |
| Settings | Manages repository configuration |

## Important elements in the Code section

- **Branch selector:** Selects a branch.
- **File list:** Displays files and folders.
- **Commits:** Shows recorded changes.
- **README:** Introduces the project.

## About section

The About section provides a short repository description, website link, and relevant topics.

Topics help categorize projects and make them easier to discover.

## Practical exercise
1. Explore the Code section.
2. Open the README file.
3. Inspect the commit history.
4. Explore Issues and Pull requests.
5. Locate Settings.
6. Inspect the About section.

## What I learned

A GitHub repository is more than a place to store files. Its different sections support project organization, collaboration, documentation, and development management.
