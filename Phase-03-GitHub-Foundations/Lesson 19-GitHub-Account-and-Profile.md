# Lesson 19: GitHub Account and Profile

## Learning objectives
- Understand the purpose of a GitHub account.
- Identify the main sections of a GitHub profile.
- Understand how a profile represents a developer.
- Recognize the importance of presenting projects clearly.

## Core idea

A GitHub account provides access to GitHub's platform for hosting repositories, managing projects, and collaborating with developers.

A GitHub profile represents a user's public identity and showcases their development activities.

## Important profile sections

| Section | Purpose |
|---|---|
| Profile picture | Represents the account |
| Username | Identifies the account |
| Bio | Introduces the user |
| Location | Shows optional location information |
| Website | Links to an external website |
| Repositories | Displays projects |
| Contributions | Shows qualifying activity |
| Pinned repositories | Highlights selected projects |

## Why it matters

A well-organized GitHub profile helps visitors understand a developer's interests, projects, skills, and learning activities.

## Practical exercise
- Review your GitHub profile.
- Check your profile information.
- Improve your bio.
- Review your repositories.
- Explore your contribution graph.

## What I learned

A GitHub profile is more than an account page. It is a public representation of a developer's projects, activities, and development journey.
