# Lesson 20: Creating GitHub Repositories

## Learning objectives
- Understand what a GitHub repository is.
- Learn how to create a repository.
- Understand repository configuration options.
- Differentiate between public and private repositories.

## Core idea

A GitHub repository is an online space for storing project files, documentation, and version history.

## Repository configuration

| Setting | Purpose |
|---|---|
| Owner | Identifies the account or organization owning the repository |
| Repository name | Gives the repository its name |
| Description | Explains the project's purpose |
| Visibility | Determines whether the repository is public or private |
| README | Provides introductory project documentation |
| .gitignore | Specifies files Git should ignore |
| License | Defines permissions for using and distributing project code |

## Public vs Private

**Public repository:** Anyone can view its contents.

**Private repository:** Access is restricted to authorized users.

## Practical exercise

1. Open GitHub's new repository page.
2. Enter a repository name and description.
3. Select public or private visibility.
4. Choose whether to initialize a README.
5. Create the repository.
6. Explore the repository page.

## What I learned

Creating a GitHub repository provides an online space to organize and manage a software project. Repository settings determine its ownership, visibility, and initial configuration.
