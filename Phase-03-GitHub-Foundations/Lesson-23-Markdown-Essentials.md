# Lesson 23: Markdown Essentials

## Learning Objectives
- Understand what Markdown is.
- Learn common Markdown syntax.
- Create formatted text, lists, links, tables, and code blocks.
- Understand GitHub Flavored Markdown.

## Core Idea
Markdown is a lightweight markup language used to format plain text. It allows developers to create readable documentation using simple symbols.

## Why It Matters
Markdown is widely used on GitHub for README files, documentation, issues, pull requests, and project notes.

## Common Markdown Syntax

| Element | Syntax |
|---|---|
| Heading | `# Heading` |
| Bold | `**text**` |
| Italic | `*text*` |
| Bullet list | `- Item` |
| Numbered list | `1. Item` |
| Link | `[Name](URL)` |
| Inline code | `` `code` `` |
| Blockquote | `> Text` |
| Divider | `---` |

## Code Blocks
Triple backticks create a code block. A language identifier can be added for syntax highlighting.

Example:

```bash
git status
git log --oneline
```

## GitHub Flavored Markdown
GitHub supports additional Markdown features, including:
- Tables
- Task lists
- Nested lists
- Automatic links

## Common Mistakes
- Forgetting spaces after heading symbols.
- Forgetting to close code blocks.
- Using incorrect link syntax.
- Forgetting blank lines between some Markdown elements.
