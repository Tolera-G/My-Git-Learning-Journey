# Lesson 25: GitHub Repository Settings

## Learning Objectives
- Understand GitHub repository settings.
- Explore important configuration sections.
- Understand repository access and permissions.
- Identify security and branch protection settings.
- Recognize potentially destructive repository actions.

## Core Idea
Repository settings are configuration options that control how a GitHub repository behaves.

They allow repository owners and authorized users to manage access, features, security, and other repository configurations.

## Why It Matters
Repository settings help developers manage projects securely, control collaboration, and protect important project resources.

## Important Repository Settings

### 1. General
Manages basic repository information and features, including:
- Repository name and description.
- Default branch.
- Repository features.
- Other general configurations.

### 2. Access
Controls who can access the repository and what permissions they have.

Examples:
- Adding collaborators.
- Managing access permissions.

### 3. Branches
Provides branch-related configuration, including branch protection and rules.

Examples:
- Requiring pull requests before merging.
- Requiring status checks.

### 4. Code and Automation
Contains configuration for automation and repository integrations.

Examples:
- GitHub Actions permissions.
- Webhooks.
- Deploy keys.

### 5. Security
Provides security-related configuration.

Examples:
- Dependabot alerts.
- Secret scanning.
- Security policies.

### 6. Danger Zone
Contains potentially destructive repository actions.

Examples:
- Changing repository visibility.
- Transferring ownership.
- Archiving a repository.
- Deleting a repository.

## Practical Demonstration
Explored the Settings tab of a practice repository and identified the General, Access, Branches, and Security sections.

## Common Mistakes and Safety Notes
- Do not change important repository settings without understanding their effects.
- Avoid experimenting with destructive actions on important repositories.
- Only authorized users can access certain settings.
- Available settings may vary depending on repository permissions and GitHub features.
