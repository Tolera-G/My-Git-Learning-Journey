# Lesson 22: README Files

## Learning objectives
- Understand the purpose of README files.
- Understand the `.md` file extension.
- Learn common Markdown formatting.
- Create and edit a README on GitHub.

## Core idea

A README is a document that introduces a project and explains important information about it.

The commonly used filename is `README.md`.

GitHub automatically renders Markdown README files on repository pages.

## Common README sections

- Project title
- Description
- Features
- Technologies used
- Installation instructions
- Usage instructions
- Screenshots
- Author
- License

Not every README needs all these sections.

## Markdown essentials

### Headings

```markdown
# Main Heading
## Section Heading
### Subsection
```

### Text formatting

```markdown
**Bold text**
*Italic text*
```

### Lists

```markdown
- First item
- Second item
```

### Links

```markdown
[GitHub](https://github.com)
```

### Images

```markdown
![Screenshot](images/homepage.png)
```

### Code blocks

````markdown
```javascript
console.log("Hello GitHub!");
```
````

## Practical exercise
1. Open a GitHub repository.
2. Edit its README.md file.
3. Add a project title and description.
4. Use Markdown headings and lists.
5. Preview the document.
6. Commit the changes.
7. Inspect the rendered README.

## What I learned

README files introduce projects and help visitors understand their purpose, structure, and usage. Markdown makes it possible to create organized documentation using simple text formatting.
